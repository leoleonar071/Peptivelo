# Peptivelo brand assets

The isotype PNG was supplied by the user in this task (clipboard image 19775aa9-db7b-46c9-b24f-3e8f29f7a24d, 1341×1173, RGBA). Copied without modification. No trace, redrawing, color substitution or generated reverse version was made. A light backing plate preserves legibility in the dark UI pending an approved reverse asset.

Manrope and Inter variable Latin WOFF2 files were downloaded from Google's official Fonts CSS/CDN responses; the response is archived at docs/research/peptivelo-font-response.css. Font licenses are public/fonts/Manrope-OFL.txt and Inter-OFL.txt. The application serves these files locally; page visitors do not request them from Google.
