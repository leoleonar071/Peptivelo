# Paquete para revisión científica

Este paquete prepara un encargo, no acredita que un profesional haya revisado la plataforma.

1. Leer **ENCARGO_PARA_PRESUPUESTO.md** y adaptar el saludo/firma antes de solicitar presupuesto.
2. Entregar **HOJA_EVALUACION.md**, **RESPUESTAS.md**, **snapshot.json**, **manifest.json** y el expediente **../SCIENTIFIC_REVIEW_FIRST_BATCH.md** como un mismo paquete.
3. Acordar alcance, precio, plazos y credenciales. Pedir presupuesto separado para las dos etapas y para cualquier ampliación.
4. Proporcionar una vista renderizada de esta versión. `127.0.0.1` solo funciona en el ordenador que ejecuta la web; no es un enlace para compartir con el revisor.
5. Conservar las respuestas recibidas como una copia nueva, vinculada al SHA-256 de la instantánea. No regenerar ni sobrescribir el paquete que el especialista esté evaluando.
6. Aplicar las correcciones, registrar los cambios y pedir nueva comprobación cuando cambie el significado. Resolver todos los pendientes necesarios antes de marcar una página revisada.

La hoja identifica 126 unidades en 13 páginas. Los resúmenes y conclusiones repetidos deben contrastarse entre sí; no deben presupuestarse automáticamente como estudios distintos. Los tres destinos del selector están mencionados, pero solo las dos comparaciones indicadas forman parte de la evaluación completa.

La revisión del texto no concede derechos sobre fotografías, no verifica el contenido de los frascos y no activa la publicación ni la indexación. Los indicadores siguen pendientes hasta una revisión real documentada.
