## Procedimiento

Usar la versión local o desplegada que se indique al iniciar la sesión. Permitir móvil o escritorio y anotarlo. Presentar las tareas sin explicar dónde están los controles. Registrar éxito sin ayuda, errores, necesidad de intervención y la explicación del participante. No sugerir que un producto debe ganar una comparación.

1. Encontrar Copper Tripeptide-1 y explicar con palabras propias qué distingue un ingrediente de un producto terminado.
2. Abrir una referencia y señalar qué respalda y qué limitación deja visible. Los lectores técnicos deben poder localizar también el tipo de fuente y el alcance de acceso.
3. Filtrar el directorio, abrir una ficha y regresar conservando la selección.

Las cuatro tareas son comunes a ambos grupos. Objetivo inicial: al menos cinco de seis participantes completan cada tarea sin ayuda. Registrar también el resultado por grupo para que el total no oculte una dificultad de principiantes o lectores técnicos. No declarar el objetivo conseguido hasta realizar las sesiones.
